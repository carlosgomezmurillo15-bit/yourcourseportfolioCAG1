Experimenting with Navigation

This exercise shows how the same group of links can look different depending on the class used on the <nav> element.

  • class="nav-simple" - vertical list navigation
  • class="nav-horizontal" - horizontal top navigation bar
  • class="nav-custom" - boxed custom navigation
  • class="nav-centered" - centered rounded navigation

All pages share the same style.css file, but nested pages need the correct relative path to load it properly.
