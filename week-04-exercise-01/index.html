Week 04 Exercise 01: Dev Tools Vandalism

For this exercise, I used the browser developer tools to temporarily modify the Texas Tech University homepage. Since Texas Tech is the university I attend, I thought it would be a fun and familiar website to experiment with.

I changed one of the main pieces of text on the homepage to say, “Texas Tech Now Runs on Cafecito, Code, and 6-Minute Miles.” I also changed the CSS styling by adjusting the text color, increasing the font size, changing the background color, and adding a dramatic text shadow. These edits were only visible locally in my browser and did not affect the real Texas Tech website.

This activity helped me understand how browser developer tools can be used to inspect, test, and temporarily change HTML and CSS directly on a live webpage.
