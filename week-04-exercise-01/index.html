My Dev Tools Vandalism

I used browser developer tools to temporarily edit the Texas Tech University homepage. These changes only appeared on my computer and did not affect the real TTU website. Below is a screenshot showing the changes I made.

What I Vandalized

For this exercise, I chose the Texas Tech University homepage because Texas Tech is my university, so it made the activity feel connected to my actual course portfolio.

I changed one of the main homepage headings to say, “Texas Tech: Powered by Cafecito, Code, and Last-Minute Assignments.” I also changed another text section to say, “From Raiderland to GitHub Pages, we are building websites one broken index file at a time.”

I also used the Styles panel in developer tools to change several CSS properties. I changed the background color, text color, font size, text shadow, and border to make the page look more dramatic and customized. This helped me understand how HTML controls the content of a page while CSS controls how that content looks.
